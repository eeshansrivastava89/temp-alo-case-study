1. Ask: “What drove Store Revenue last week, and where should we act?”
2. Point out the exact period, comparison, evidence-linked exhibit, action, and method/source disclosure.
3. Ask: “Which stores explain the decline?” to demonstrate follow-up context.
4. End on the Executive Dashboard.

# Presentation

- Editable deck: [`ALO_AI_Business_Analyst_Case_Study.pptx`](ALO_AI_Business_Analyst_Case_Study.pptx)
- Live app: https://temp-alo-case-study-clyugcdbazahif33twk2ss.streamlit.app/

- Expected demo video: [`../demo/alo_business_analyst_demo.mp4`](../demo/alo_business_analyst_demo.mp4)

The deck contains five slides and speaker notes. It uses an original consulting-style layout informed by public McKinsey/BCG presentation conventions: action titles, one primary exhibit, restrained color, direct labels, and source footnotes. It does not use either firm's branding or a proprietary template.

To rebuild locally:

```bash
pip install python-pptx qrcode pillow
python presentation/build_deck.py
```
